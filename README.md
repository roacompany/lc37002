# PDF → PPT 변환기

PDF를 PowerPoint(.pptx)로 변환하는 웹사이트입니다. 변환은 모두 브라우저 안에서 이루어지므로 파일이 서버로 업로드되지 않고, 별도 백엔드 없이 정적 호스팅(GitHub Pages 등)만으로 운영할 수 있습니다.

## 변환 방식

| 방식 | 결과 | 용도 |
| --- | --- | --- |
| **편집 가능** (기본) | 텍스트를 지운 페이지 이미지를 배경으로 깔고, 그 위에 원래 위치·크기·색상·굵기·기울임을 맞춘 텍스트 상자를 올림 | 문구 수정이 필요한 경우 |
| **원본 그대로** | 각 페이지를 고해상도 이미지 한 장으로 넣음 | 모양이 100% 같아야 하는 경우 |

편집 가능 모드의 동작 원리:

1. pdf.js로 페이지를 한 번 렌더링하면서 캔버스에 그려지는 글자 하나하나의 위치와 색을 기록합니다.
2. `getTextContent()`로 얻은 정확한 유니코드 텍스트와 1의 글자 위치를 맞춰, 줄 단위 텍스트 상자와 색·글꼴별 구간(run)으로 묶습니다.
3. 텍스트 상자로 옮긴 글자만 빼고 페이지를 다시 렌더링해 배경 이미지를 만듭니다. 도형·표 테두리·사진·그라데이션은 배경에 그대로 남습니다.
4. 대체 폰트를 써도 줄 폭이 원본과 같도록 자간을 보정하고, PDF의 웹 링크는 슬라이드 하이퍼링크로 옮깁니다.

## 글자 인식 (OCR)

스캔한 PDF처럼 글자가 이미지로만 들어 있는 경우 [tesseract.js](https://github.com/naptha/tesseract.js)(WASM)로 한국어·영어를 인식해 편집 가능한 텍스트로 바꿉니다. 엔진과 학습 데이터도 같은 사이트에서 내려받으므로 OCR 중에도 파일이 외부로 전송되지 않습니다. 처음 OCR을 쓸 때 약 8MB를 내려받고, 이후에는 브라우저에 캐시됩니다.

| 옵션 | 동작 |
| --- | --- |
| 스캔 페이지만 (기본) | PDF 텍스트가 없는 페이지에만 OCR 실행 |
| 모든 페이지 | 모든 페이지에서, PDF 텍스트를 지운 배경 이미지 속 글자(사진·캡처 이미지 속 글자 등)까지 인식 |
| 사용 안 함 | OCR을 하지 않음 |

- OCR은 PDF 텍스트를 이미 지운 배경에 대해 실행하므로 같은 글자가 두 번 들어가지 않습니다.
- 300dpi로 다시 렌더링하고 회색조로 바꾼 뒤, 흩어진 텍스트에 강한 SPARSE_TEXT 모드로 인식합니다.
- 글자 크기·기준선은 단어 상자 높이로 추정하고(한글 음절 ≈ 0.9em 등 실측 비율), 글자색과 배경색은 픽셀에서 직접 구합니다. 인식한 자리는 주변 배경색으로 지웁니다.
- 표 테두리를 `|`, `[`로 잘못 읽은 것은 걸러내고 그 자리에서 텍스트 상자를 나눠 칸별 위치를 유지합니다.
- 인식 신뢰도가 낮은 구간은 텍스트로 바꾸지 않고 원래 이미지로 남깁니다.

## 한계

- 도형·표·차트는 배경 이미지에 포함되며, PowerPoint 도형으로 편집할 수는 없습니다.
- 회전된 텍스트, 세로쓰기, Type3 글꼴, 윤곽선만 있는 텍스트는 편집 가능한 텍스트로 바꾸지 않고 배경 이미지에 그대로 남깁니다.
- OCR 결과는 100% 정확하지 않습니다(예: `Q3` → `03`). 신뢰도가 낮은 부분은 이미지로 남지만, 잘못 읽은 글자가 텍스트로 들어갈 수 있습니다. 기울어진 스캔, 손글씨, 한국어·영어 외 언어는 인식률이 낮습니다.
- OCR로 지운 자리는 단색으로 채우므로, 사진이나 그라데이션 위의 글자는 지운 흔적이 보일 수 있습니다.
- PDF에 내장된 글꼴은 PPTX에 넣을 수 없습니다. 같은 이름의 글꼴이 PowerPoint를 여는 PC에 없으면 비슷한 기본 글꼴(맑은 고딕, Arial, Times New Roman, Courier New)로 바뀝니다.
- 암호가 걸린 PDF는 지원하지 않습니다.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성
npm run preview  # 빌드 결과 확인
```

`npm run dev`/`build` 전에 런타임 파일이 자동 복사됩니다: pdf.js의 CMap(한글 등 CJK 글꼴용)·표준 글꼴·WASM 디코더는 `public/pdfjs/`로, OCR 엔진·한국어/영어 학습 데이터는 `public/tesseract/`로.

## 배포

`main` 브랜치에 push하면 `.github/workflows/deploy.yml`이 GitHub Pages에 배포합니다. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 설정해야 합니다.

## 구조

- `src/converter.js` — PDF 렌더링, 텍스트 추출·병합, PPTX 생성
- `src/ocr.js` — OCR 실행, 줄·색 구간 구성, 글자 크기 추정, 인식한 글자 지우기
- `src/fonts.js` — PDF 글꼴 이름을 PowerPoint 글꼴로 매핑, 설치 여부 확인, 텍스트 폭 측정
- `src/main.js` — 업로드·옵션·진행률 UI
